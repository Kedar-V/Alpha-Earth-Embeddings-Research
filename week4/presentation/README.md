# Week 4 presentation (localhost)

Live deck for iterative editing in the Cursor browser.

## Open

```bash
# from repo root (already running on 8765 if started)
python3 -m http.server 8765 --bind 127.0.0.1
```

**URL:** http://127.0.0.1:8765/week4/presentation/index.html

## Edit loop

1. Edit `week4/presentation/index.html`
2. Refresh the browser tab (or tell the agent what to change)
3. Jump to a slide with `#N` (e.g. `#13` for Atlanta vs NYC)

Keys: `←` `→` / Space · `F` fullscreen
